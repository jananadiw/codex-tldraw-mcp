# codex-tldraw-mcp v0.6.0

Portable SVG previews for any MCP host.

## Highlights

- Saves `<board>.svg` beside every editable `<board>.tldr` file.
- Returns `svgPath` in structured tool output and an `image/svg+xml` MCP resource link in tool content.
- Adds a readable SVG board resource at `tldraw://boards/{name}/svg`.
- Refreshes the preview whenever a diagram is appended or code graph drift markers change.
- Uses a small server-side renderer with no browser runtime or new production dependency.

## Output

```text
<repo>/boards/main.tldr
<repo>/boards/main.svg
```

The `.tldr` file remains the editable source of truth. The SVG is a portable projection of the text, rectangle, and arrow shapes generated by this server, suitable for chat hosts, browsers, documentation, CI artifacts, and code reviews.

## Compatibility

Existing tool inputs and `.tldr` behavior are unchanged. MCP hosts that ignore resource links can use `svgPath` from structured output. Read-only code graph drift previews do not modify either artifact.

## Verification

```bash
bun install --frozen-lockfile
bun run build
bun run smoke
bun run check:package
mcp-publisher validate
```
